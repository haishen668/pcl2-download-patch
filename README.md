# PCL2 下载恢复补丁

一键恢复 PCL2 最新版（2.99.0.0）中被移除的 **Minecraft 下载功能**。

## 使用方法（共 3 步）

1. 从 [**Releases 页面**](../../releases) 下载 **RestoreDownload.exe**
2. 把它放进 PCL 文件夹（和 `Plain Craft Launcher 2.exe` 同一个文件夹）
3. **双击运行**，看到"已恢复"就完成了

<div align="center">

```
下载 → 放进 PCL 文件夹 → 双击
```

</div>

**想还原？** 删掉 PCL 的 exe，把文件夹里的 `.bak` 文件改回原来的名字。
**PCL 更新后又失效？** 重新双击一次本工具即可。

## 常见问题

**双击后提示"没有找到下载限制标记"**
你的 PCL 版本尚未受限，或限制结构有变化。请到 [Issues](../../issues) 附上 PCL 版本号。

**杀毒软件报警？**
本工具只修改 60 个字节、自动备份原文件，且全程不上传任何数据，属误报。介意的话可以[读一遍源码](src/Patcher/Program.cs)（约 300 行，做的是什么一目了然）。

**为什么不直接提供改好的 PCL？**
① PCL 的[分发许可](https://github.com/Meloong-Git/PCL)禁止再分发其程序；② 事件后网盘和群里流传的"恢复版 PCL"**已出现病毒**。本仓库只发布我们自己编写的小补丁工具，不包含任何 PCL 代码——这是它比来路不明的"现成恢复版"安全的原因。

**它到底改了 PCL 的什么？**
移除下载拦截、把下载页的"假加载器"换回真的、恢复一张被隐藏的设置卡片。全部细节见[技术分析](docs/how-it-works.md)。

**不想用 exe？**
命令行用户的替代品：[restore-download.ps1](src/restore-download.ps1)（右键 → 使用 PowerShell 运行，或 `powershell -ExecutionPolicy Bypass -File restore-download.ps1`）。
